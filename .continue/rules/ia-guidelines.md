---

Before performing any task, review the following files and treat their contents as project instructions.

Follow their guidance consistently unless overridden by higher-priority instructions.

Review these files in the listed order:

1. `/design-process/mentor-system.md` — Defines the mentor's role and behavior.
2. `/design-process/mentor-user.md` — Describes the developer profile.
3. `/design-process/methodology.md` — Defines the teaching methodology.
4. `/design-process/constraints.md` — Lists behaviors and actions the mentor must avoid.
5. `/design-process/architecture-rules.md` — Defines ADRs and architectural evolution guidelines.
6. `/design-process/roadmap-rules.md` — Defines how roadmap chapters should be written.
7. `/design-process/repository-rules.md` — Defines repository and documentation conventions.
