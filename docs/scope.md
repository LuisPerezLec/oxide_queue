# Scope

### OxideQueue will eventually
* Execute tasks asynchronously.
* Allow users to define executable tasks.
* Report failures to callers.
* Inform callers whether task submission succeeded.
* Preserve task execution results for later retrieval..
* Handle and store task finish status
* Execute multiple tasks concurrently.
* Support recurring task execution.
* Support execution across multiple machines.

### OxideQueue will not
* Support third party brokers
* Support priority tasks
